yt-dlp's EJS solver (https://github.com/yt-dlp/ejs), release 0.8.0, Unlicense (meriyah: ISC, astring: MIT, bundled).
It reads YouTube's player script and answers its `n` and signature challenges; the Android app runs it in a
hidden WebView (Cipher.kt / WebSolver.kt) for the videos only the TV client serves (made for kids, some labels).
